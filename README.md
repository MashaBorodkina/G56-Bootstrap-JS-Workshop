# 🧩 Workshop: Bootstrap To-Do List

In this workshop, you will **build a simple To-Do List web page** using **HTML**, **CSS**, and **Bootstrap 5**.  
The goal is to gain **hands-on experience** in structuring a static, responsive web layout.  
Later, you will add interactivity with **JavaScript**.

---

## 🎯 Task

Create a **static layout** using HTML, CSS, and Bootstrap 5 that **visually matches the layout** shown in _Figure 1_ of the assignment.

### Use:

- 🧱 **HTML** — to define the page structure
- 🎨 **CSS** — for basic styling
- ⚙️ **Bootstrap 5** — to simplify and speed up responsive layout design

> 🪄 Interactivity will be added later with JavaScript.

---

## 💡 Optional Tasks

- Add an icon library such as **Font Awesome** or **Bootstrap Icons** to enhance the UI.
- Import and apply **Google Fonts** to improve typography and visual appeal.
